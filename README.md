# 还款记录（Android 版）

记录信用卡账单日与还款日的安卓原生应用：Kotlin + Jetpack Compose。
与同名 iOS 版功能、计算逻辑、卡面颜色、界面排版完全一致（两边数据不互通，都是本机存储）；数据只存本机，不联网、不收集。

## 功能一览

- 最多 5 个用户，点顶部横幅切换；每个用户数据完全独立，名字可改；删用户连卡一并删（至少保留 1 个）
- 顶部横幅大小固定，每个用户一栏横排；当前用户的栏位带「被按下去」的凹陷效果
- 卡片一行一张：大数字剩余还款天数 + 剩余量进度条（越近还款日越短，到期归零变红）
- 到期/逾期出现「已还款」按钮：点后才进入下一周期，不点继续显示 -1 天、-2 天
- 还款方式三种：固定日期 / 账单日后天数 / 单次
  - 数字可直接点开输入，也可加减微调，超范围自动夹回
  - 单次：只填一个天数（1–36500），从保存当天起算唯一还款日，点已还款后「已结束」，永不循环
- 到期提醒：顶栏铃铛开关，开启后在还剩 1 天、到期当天、逾期时于上午 9:00 发本地通知
- 卡面颜色 18 种；普通/极简模式切换（极简只显示名字＋天数＋进度条，选择会记住）
- 月历：红点还款日、灰点账单日，点某天看当天事项
- 左上角是作者标识（「行動君 kodokun」头像＋「打赏作者」），点开是打赏弹窗

## 怎么打开和运行

1. 电脑上装 **Android Studio**（Ladybug 或更新版本，自带 JDK 17）
2. 克隆或下载本仓库，Android Studio 里选「Open」打开工程根目录
3. 首次打开会自动下载 Gradle 与依赖（需要联网，几分钟）；如果提示创建/更新 Gradle Wrapper，点同意即可（本工程只带了 wrapper 配置文件，jar 由 Android Studio 生成）
4. 接上安卓手机（开 USB 调试）或用内置模拟器，点绿色运行按钮即可装到手机上试用

## 打包 APK（装到自己手机上，不上架也能用）

Android Studio 菜单：Build → Build App Bundle(s) / APK(s) → Build APK(s)，
生成的 `app/build/outputs/apk/debug/app-debug.apk` 传到手机上点开即可安装。
正式发布版请用 Build → Generate Signed App Bundle / APK，按向导生成**你自己的**签名密钥再打 release 包。

> 说明：本展示仓库不包含作者的签名密钥文件与自动打包配置，`app/build.gradle.kts` 中的 release 签名是从环境变量读取的，换成自己的密钥即可；打赏弹窗里的支付宝 / 微信收款码在展示版中已替换为占位图。

## 环境

- 最低系统：Android 8.0（API 26）
- 包名：com.paydaycalendar.app（与 iOS 版 Bundle ID 相同，各商店互不影响）
